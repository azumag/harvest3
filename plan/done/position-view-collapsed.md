# ポジション欄の初期表示状態を閉じる実装計画

## 概要
ダッシュボード画面（src/web/index.html）の「現在のポジション」欄の初期表示状態を、開いている状態から閉じている状態に変更します。

## 背景
現在のダッシュボード画面では、「現在のポジション」欄が初期表示時に開いた状態で表示されています。ユーザーからの要望で、この部分は初期状態では閉じられていて、必要に応じてクリックして開けるようにしたいとのことです。

## 技術的詳細

### 対象ファイル
- `src/web/js/dashboard.js`

### 課題
現在、`dashboard.js`の`displayPositionGroupContent`関数内で、ポジションデータを表示する際のHTMLテンプレートに`collapse show`クラスが使用されています。これにより、Bootstrap 5の機能で初期状態が「開いている」状態になっています。

```javascript
// 現在の実装（約276行目）
<div class="collapse show" id="${groupId}">
```

### 解決策
`collapse show`クラスから`show`を削除し、単に`collapse`だけにすることで、初期状態を「閉じている」状態に変更します。

```javascript
// 修正後
<div class="collapse" id="${groupId}">
```

### 実装手順
1. `src/web/js/dashboard.js`ファイルを開く
2. 約276行目にある`<div class="collapse show" id="${groupId}">`を見つける
3. `"collapse show"`を`"collapse"`に変更する
4. 変更を保存する
5. ブラウザでダッシュボードページを開き、「現在のポジション」欄が閉じた状態で初期表示されることを確認する

## 期待される動作
- ダッシュボードページ初期表示時、「現在のポジション」欄は閉じた状態で表示される
- ユーザーがヘッダー部分をクリックすると、ポジション情報が展開される
- 再度ヘッダー部分をクリックすると、ポジション情報が折りたたまれる

## 注意点
- この変更はUIの初期表示のみに影響し、機能的な変更はありません
- ポジションデータの取得や処理ロジックには影響しません
