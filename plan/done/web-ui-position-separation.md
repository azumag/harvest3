# ポジション詳細の分離計画

## 目的
ダッシュボード画面が縦長になりすぎる問題を解決するため、ポジションの詳細情報を別ページに分離する。

## 実装計画

### 1. 新しいポジション詳細ページの作成
- `positions.html` という新しいページを作成
- 現在のポジションの詳細情報をこのページに移動
- 専用のJavaScriptファイル（`positions.js`）を作成

### 2. ダッシュボードの修正
- `index.html` のポジション表示をサマリー情報のみに簡略化
  - 各ポジションの銘柄名と実現損益のみを表示
  - 詳細ページへのリンクを追加
- `dashboard.js` の関連部分を修正

### 3. ナビゲーションの更新
- ナビゲーションメニューに「ポジション」リンクを追加

## 詳細設計

### positions.html
- 基本的なレイアウトは `index.html` と同様
- ナビゲーションバーを含む
- ポジション一覧を表示するコンテナ
- フィルタリングオプション（取引所、銘柄、戦略別）

### positions.js
- APIからポジション情報を取得
- 詳細なポジション情報を表示
- フィルタリング機能の実装
- リアルタイム更新の設定

### dashboard.js の修正
- `loadPositions` 関数を簡略化
- 各ポジションの銘柄名と実現損益のみを表示
- 詳細ページへのリンクを追加

## 実装手順
1. `positions.html` ファイルの作成
2. `positions.js` ファイルの作成
3. `index.html` のナビゲーションメニュー更新
4. `dashboard.js` のポジション表示部分修正
5. テストと動作確認
