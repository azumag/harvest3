# バックテストスクリプト backtestRunner.js 作成計画

## 概要
`plan/backtest/backtest-step3.md` に基づくバックテストスクリプト `backtestRunner.js` の作成計画です。

## 計画詳細
1.  **スクリプトの基本構造:** `src/bot.js` を参考に、戦略をループ実行する基本構造を作成します。ただし、リアルタイムのループではなく、指定した期間のタイムスタンプを生成してループさせます。
2.  **時間生成とループ:** 1年前から指定した日付（4/29）までのタイムスタンプを、OHLCV の timeframe 刻みで生成します。このタイムスタンプをループの各ステップで使用します。
3.  **戦略の起動:** `src/bot.js` の `runStrategy` 関数に相当する処理を実装します。バックテスト用に `options:backtest` を作成し、生成したタイムスタンプを含めて戦略に渡します。
4.  **データ取得:** `marketParameter` と `symbolByExchange` はループの前に一度だけ取得し、使い回します。OHLCV データは、バックテストのタイムスタンプに基づいて取得する必要があります。これは `scripts/fetchBitbankOHLCV.js` が参考になるかもしれません。
5.  **結果の保存とレポート:** 戦略の実行結果を保存し、バックテスト終了後にレポートを生成・投稿する機能を実装します。レポートの投稿は Discord を想定していますが、バックテスト中は通知をオフにする必要があります。
6.  **Discord 通知の無効化:** シグナルや注文に関する Discord 通知は、バックテスト実行中は無効にします。これは `src/common/notifications.js` の関数をラップするか、条件分岐で通知をスキップすることで実現できるでしょう。
