# 相互情報量戦略 (Mutual Information Strategy)

通貨間・取引所間の相互情報量を基準とした取引戦略の実装です。

## 概要

この戦略は、複数の通貨ペアまたは取引所間の価格データから相互情報量を計算し、その情報を基にして売買シグナルを生成します。相互情報量は、二つの変数間の統計的依存性を測定する情報理論の指標です。

## 主な特徴

- **相互情報量計算**: 時系列データ間の統計的相関を情報理論的に分析
- **複数シンボル対応**: 複数の通貨ペア間の関係性を同時に分析
- **適応的取引ロジック**: 相関の強さに応じて異なる取引戦略を採用
  - 高い相互情報量（強い相関）→ トレンドフォロー戦略
  - 低い相互情報量（弱い相関）→ 平均回帰戦略
- **設定可能なパラメータ**: 分析期間、閾値、参照シンボル、分析モードを調整可能

## 使用方法

```javascript
const { mutualInformationStrategy } = require('./src/strategies/mutualInformation');

const config = {
  period: 50,                    // 分析期間
  threshold: 0.5,                // シグナル生成の閾値
  referenceSymbols: ['BTC/USDT', 'ETH/USDT'], // 参照する通貨ペア
  ohlcvInterval: '5m',           // 時間足
  useReturns: true               // リターン（価格変化率）を使用するか
};

const result = await mutualInformationStrategy(
  exchange,      // 取引所オブジェクト
  'ADA/USDT',    // 取引対象の通貨ペア
  'mi-strategy', // 戦略キー
  config,        // 設定
  marketParameters, // 市場パラメータ
  options        // オプション
);
```

## アルゴリズム

1. **データ収集**: メインシンボルと参照シンボルのOHLCVデータを取得
2. **前処理**: 価格データまたは価格変化率を計算
3. **相互情報量計算**: 各参照シンボルとの相互情報量を計算
4. **シグナル生成**: 
   - 平均相互情報量が閾値より高い場合 → トレンドフォロー
   - 平均相互情報量が閾値より低い場合 → 平均回帰
5. **取引実行**: 生成されたシグナルに基づいて売買注文を実行

## 設定パラメータ

| パラメータ | デフォルト値 | 説明 |
|-----------|-------------|------|
| `period` | 50 | 分析に使用する過去のデータ数 |
| `threshold` | 0.5 | 相互情報量の閾値 |
| `referenceSymbols` | ['BTC/USDT'] | 比較対象の通貨ペア |
| `ohlcvInterval` | '5m' | ローソク足の時間足 |
| `useReturns` | true | 価格変化率を使用するか（falseの場合は価格そのものを使用） |

## 理論的背景

相互情報量 I(X;Y) は以下の式で計算されます:

```
I(X;Y) = Σ p(x,y) * log(p(x,y) / (p(x) * p(y)))
```

ここで:
- p(x,y) は結合確率分布
- p(x), p(y) は周辺確率分布

この指標は、二つの変数が独立である場合は0になり、完全に依存している場合は最大値を取ります。

## 注意事項

- 十分な履歴データが必要（最低でも期間の半分以上）
- 計算コストがデータ量に比例して増加
- 相関関係と因果関係は異なることに注意
- 市場の急激な変化時には適応が遅れる可能性
