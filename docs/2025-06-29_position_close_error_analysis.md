# ポジションクローズ失敗エラー調査・修正レポート

**日付**: 2025-06-29  
**調査対象**: 複数のポジションクローズ失敗エラー  
**担当**: Claude Code

## #1 エラー概要

### 発生エラー
複数のDiscord通知で以下のポジションクローズ失敗が報告：

```
🚨 **重要: ポジションクローズ失敗**
約定ID: 1413119156, 1413124550, 1413124788, etc.
注文ID: 47265999261, 47268076943, 47268138220, etc.
ポジションキー: bitbank:CYBER/JPY:オシレーター戦略, RENDER/JPY:BB戦略, LPT/JPY:MA戦略, etc.
エラー: ポジションクローズ失敗
```

### 調査期間
23:31 - 23:46 に集中して発生

## #2 根本原因の特定

### 初期分析
最初の分析では Redis/MongoDB 接続エラーが疑われた：
- `getaddrinfo ENOTFOUND redis`
- `getaddrinfo ENOTFOUND mongodb`

### 実際の原因
詳細調査の結果、**ポジション不整合**が根本原因であることが判明：

#### ポジション不整合の詳細
```
❌ 不整合が検出された通貨:
🏦 bitbank - ASTR:
   取引所保有量: 557.15990000
   Redis合計: 287.40370000
   差分: 269.75620000 (48.42%)

🏦 bitbank - GRT:
   取引所保有量: 0.39450000
   Redis合計: 0.31820000
   差分: 0.07630000 (19.34%)

🏦 bitbank - SOL:
   取引所保有量: 0.11730000
   Redis合計: 0.07170000
   差分: 0.04560000 (38.87%)
```

## #3 実施した修正

### 1. 環境変数の修正
**問題**: .envファイルとdocker-compose.ymlでホスト名が混在  
**修正**: サービス名による統一

#### .envファイル修正
```bash
# 修正前
REDIS_URL=redis://harvest3-redis:6379
MONGO_URL=mongodb://harvest3-mongodb:27017

# 修正後
REDIS_URL=redis://redis:6379
MONGO_URL=mongodb://mongodb:27017
```

#### docker-compose.yml修正
```yaml
# ハードコードされた環境変数を削除し、.envファイルに統一
services:
  bot:
    env_file:
      - .env
    # environment: セクションから REDIS_URL, MONGO_URL を削除
```

### 2. 接続確認
Docker Compose ネットワーク内での名前解決と接続を確認：
```bash
# bot コンテナ内での確認
Redis接続成功
MongoDB接続成功
```

## #4 ポジション不整合の分析

### 不整合の特徴
1. **Redis記録 < 取引所残高**: システムが認識している以上の資産が存在
2. **戦略別不整合**: 複数戦略での資産管理における同期問題
3. **未追跡資産**: システム外で取得された資産（JPY, MKR, SAND等）

### エラーメッセージ
```
[約定処理] ポジションクローズ失敗 (試行1/3): 47267894238 - ポジションクローズ失敗
The number of possessions is insufficient
```

## #5 修正効果

### 環境接続の改善
- Redis/MongoDB接続エラーは解消
- Docker Compose ネットワークでの正常な名前解決を確認

### 残存課題
ポジション不整合は接続修正では解決されず、別途対応が必要：
- データ同期の改善
- 手動取引の適切な反映
- 戦略間での資産管理統一
