# 残高整合性チェッカー

Redis上で管理されているポジション情報と取引所の実際の残高を比較し、不整合を検出するツールです。

## 機能

- 🔍 **全戦略チェック**: 有効な全戦略の残高整合性を一括チェック
- 📊 **詳細レポート**: 不整合の詳細と原因分析を表示
- 🚨 **Discord通知**: 重要な不整合をDiscordに自動通知
- 🎯 **個別チェック**: 特定の通貨ペア・戦略のみをピンポイントチェック

## 使用方法

### 1. 全戦略の残高チェック

```bash
# npmコマンドで実行
npm run check-balance

# または直接実行
node scripts/balanceConsistencyChecker.js
```

### 2. 特定通貨ペアのチェック

```bash
# 特定の取引所・通貨ペア・戦略をチェック
node scripts/balanceConsistencyChecker.js bitbank LINK/JPY BOLLINGER_BANDS

# Docker環境から実行する場合
docker compose exec bot npm run check-balance
docker compose exec bot node scripts/balanceConsistencyChecker.js bitbank LINK/JPY MA
```

## チェック基準

### 不整合判定条件
- **絶対差**: 0.001以上の差がある
- **相対差**: 1%以上の乖離がある
- **最小閾値**: 0.0001以上の残高/ポジションのみチェック対象

### チェック対象
- **オープンポジション**: `status = 'open'` かつ `side = 'buy'`
- **有効戦略**: `config.strategies[strategy].enabled = true`
- **全通貨**: 実残高またはポジション残高がある全ての通貨

## Discord通知

### 通知タイミング
- **不整合検出時**: エラーチャンネルに送信
- **正常時**: 通常チャンネルに送信

### 通知内容
- チェック件数・不整合件数・警告件数
- 主要な不整合の詳細（上位5件）
- 実行時刻

## トラブルシューティング

### よくある不整合の原因

1. **部分約定**: 注文が部分的にしか約定していない
2. **手動取引**: 取引所で直接行った取引がRedisに反映されていない  
3. **他戦略との競合**: 複数戦略が同じ通貨を取引している
4. **ネットワークエラー**: 注文実行時のタイムアウトやエラー
5. **Redis障害**: ポジション保存時の障害

### 修正方法

1. **軽微な不整合** (< 5%): 自然に解消される可能性があるため経過観察
2. **重要な不整合** (>= 5%): 手動でポジション情報を修正
3. **継続的な不整合**: 戦略の実装を見直し

## 定期実行の設定

```bash
# crontabで1時間毎に実行
0 * * * * cd /path/to/harvest3 && npm run check-balance >> /var/log/balance-check.log 2>&1

# 朝9時に詳細チェック
0 9 * * * cd /path/to/harvest3 && npm run check-balance
```

## 注意事項

- 取引所APIのレート制限に注意（大量チェック時）
- チェック中は新規取引が発生する可能性があるため、結果は参考値として扱う
- Redis接続エラー時は適切にフォールバック処理される
