# Harvest3 テストスクリプト

## バグ修正検証スクリプト

### Issue #128: BNB/JPY オープンオーダー取得エラー修正の検証

このバグ修正は、bitbankでサポートされていない通貨ペア（例：BNB/JPY）に対するAPIリクエスト時に発生していた
「API authentication failed」というエラーを解決します。

#### 修正内容

- `clearPositionMarket` 関数を修正し、APIリクエストを送信する前に通貨ペアが取引所でサポートされているかを確認するようにしました
- サポートされていない通貨ペアの場合、適切なエラーメッセージを表示し、処理を続行できるようにしました

#### 検証方法

次のスクリプトを実行して修正が適切に機能するか確認できます：

```bash
node test/verifyFixForIssue128.js
```

このスクリプトは以下を実行します：

1. Bitbank APIクライアントを初期化
2. サポートされているマーケットを取得
3. 有効なシンボル（BTC/JPY）でテスト実行
4. 無効なシンボル（BNB/JPY）でテスト実行
5. 検証結果のサマリーを表示

#### 期待される結果

- 有効なシンボルの場合：通常通り処理が行われる
- 無効なシンボルの場合：処理がエラーで中断せず、適切なメッセージと共に `{ success: false, reason: 'unsupported symbol' }` が返される

これにより、バックテスト実行時やポジション解消時に対象のシンボルがサポートされていなくても、
エラー状態にならずに処理が継続できるようになりました。
